The Badge is a small inline label with color, variant and size options. It takes
its text from a `label` prop or from its default slot, and carries no behavior of
its own.

## Props

| Prop      | Type                                                                                                          | Default     | Description                                     |
| --------- | ------------------------------------------------------------------------------------------------------------- | ----------- | ----------------------------------------------- |
| `label`   | `string`                                                                                                      | —           | Badge text content; overridden by the default slot. |
| `color`   | `"primary" \| "secondary" \| "success" \| "info" \| "warning" \| "error" \| "light" \| "dark" \| "neutral"` | `"neutral"` | Color variant.                                  |
| `variant` | `"solid" \| "outline" \| "soft" \| "subtle"`                                                                  | `"solid"`   | Style variant.                                  |
| `size`    | `"xs" \| "sm" \| "md" \| "lg" \| "xl"`                                                                        | `"sm"`      | Size variant.                                   |

`label` is declared on `BadgeBaseProps`; `color`, `variant` and `size` come from
the `badge` Styleframe recipe, so their unions and defaults are the recipe's.

## Events

The Badge emits no events.

## Slots

| Slot      | Description                                                       |
| --------- | ----------------------------------------------------------------- |
| `default` | Badge content. Falls back to the `label` prop when left empty. |

## Composition

`IBadge` is a styled wrapper around a headless base, `IBadgeBase`, which renders
the element and its content and nothing else. Import the base from
`@inkline/<framework>/headless` when you want the Badge's structure under your
own CSS — see
[Your first component](/docs/getting-started/first-component#drop-the-styling-the-headless-layer).
