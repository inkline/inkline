The Button is an action element with color, variant and size options, plus
`disabled`, `loading` and `block` states. It is authored once in `.ink.tsx` and
compiled to all seven frameworks.

## Props

| Prop       | Type                                                                                                          | Default     | Description                                          |
| ---------- | ------------------------------------------------------------------------------------------------------------- | ----------- | ---------------------------------------------------- |
| `label`    | `string`                                                                                                      | —           | Button text content; overridden by the default slot. |
| `color`    | `"primary" \| "secondary" \| "success" \| "info" \| "warning" \| "error" \| "light" \| "dark" \| "neutral"` | `"neutral"` | Color variant.                                       |
| `variant`  | `"solid" \| "outline" \| "soft" \| "subtle" \| "ghost" \| "link"`                                             | `"solid"`   | Style variant.                                       |
| `size`     | `"xs" \| "sm" \| "md" \| "lg" \| "xl"`                                                                        | `"md"`      | Size variant.                                        |
| `type`     | `"button" \| "submit" \| "reset"`                                                                             | `"button"`  | Native button type.                                  |
| `disabled` | `boolean`                                                                                                     | `false`     | Disables the button.                                 |
| `loading`  | `boolean`                                                                                                     | `false`     | Shows a spinner and disables the button.             |
| `block`    | `boolean`                                                                                                     | `false`     | Renders a full-width button.                         |

`label`, `type`, `disabled` and `loading` are declared on `ButtonBaseProps`;
`block` on `ButtonProps`. `color`, `variant` and `size` come from the `button`
Styleframe recipe, so their unions and defaults are the recipe's.

`loading` implies `disabled` — a loading button is not clickable, and reports
`aria-busy="true"`.

## Events

The Button emits no events. Attach a native click handler the way your framework
normally does.

## Slots

| Slot      | Description                                                     |
| --------- | --------------------------------------------------------------- |
| `default` | Button content. Falls back to the `label` prop when left empty. |

## Composition

`IButton` is a styled wrapper around a headless base, `IButtonBase`, which
carries the behavior and none of the styling. Import the base from
`@inkline/<framework>/headless` when you want the button's mechanics under your
own CSS — see
[Your first component](/docs/getting-started/first-component#drop-the-styling-the-headless-layer).
