The Field Group joins bordered controls placed as its direct children — inputs,
buttons, selects, badges — into a single unit, merging their border radii and
collapsing the inner seams. It is the supported way to attach controls outside an
input.

## Props

| Prop          | Type                              | Default        | Description                                     |
| ------------- | --------------------------------- | -------------- | ----------------------------------------------- |
| `orientation` | `"horizontal" \| "vertical"`      | `"horizontal"` | Direction the children are joined in.           |
| `block`       | `"true" \| "false" \| boolean`    | `"false"`      | Stretches the group to the full container width. |
| `id`          | `string`                          | —              | Id of the field group element.                  |

`id` is declared on `FieldGroupBaseProps`; `orientation` and `block` come from
the `field-group` Styleframe recipe, so their unions and defaults are the
recipe's. Boolean recipe axes accept either a real boolean or its string form —
the recipe stringifies the value before matching.

## Events

The Field Group emits no events.

## Slots

| Slot      | Description                                                                 |
| --------- | --------------------------------------------------------------------------- |
| `default` | The controls to join. Only direct children take part in the seam collapsing. |

## Composition

`IFieldGroup` is a styled wrapper around a headless base, `IFieldGroupBase`,
which renders the container element and nothing else. Import the base from
`@inkline/<framework>/headless` when you want the structure under your own CSS —
see
[Your first component](/docs/getting-started/first-component#drop-the-styling-the-headless-layer).
