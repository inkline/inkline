The Hamburger Menu is an icon-only toggle for showing and hiding a navigation
region. It owns a two-way `open` state, reports it as `aria-expanded`, and
morphs its bars into one of seven shapes while open.

## Props

| Prop           | Type                                                                                            | Default           | Description                                          |
| -------------- | ----------------------------------------------------------------------------------------------- | ----------------- | ---------------------------------------------------- |
| `open`         | `boolean`                                                                                       | —                 | Two-way disclosure state. Pairs with `update:open`.  |
| `color`        | `"light" \| "dark" \| "neutral"`                                                                | `"neutral"`       | Color variant.                                       |
| `size`         | `"sm" \| "md" \| "lg"`                                                                          | `"md"`            | Size variant.                                        |
| `animation`    | `"close" \| "arrow-up" \| "arrow-down" \| "arrow-left" \| "arrow-right" \| "minus" \| "plus"` | `"close"`         | Shape the bars morph into while open.                |
| `ariaLabel`    | `string`                                                                                        | `"Toggle menu"`   | Accessible name for the icon-only toggle.            |
| `ariaControls` | `string`                                                                                        | `""`              | Id of the region the toggle shows and hides.         |
| `disabled`     | `boolean`                                                                                       | —                 | Disables the toggle.                                 |

`ariaLabel`, `ariaControls` and `disabled` are declared on
`HamburgerMenuBaseProps`; `color`, `size` and `animation` come from the
`hamburger-menu` Styleframe recipe, so their unions and defaults are the
recipe's.

The recipe also has an `active` axis, but it is not a prop: the component derives
it from `open` and sets it itself.

## Events

| Event         | Payload   | Description                                  |
| ------------- | --------- | -------------------------------------------- |
| `update:open` | `boolean` | Fired when the toggle is clicked, with the new state. |

`open` and `update:open` are the two halves of one `defineModel`. In frameworks
that support it, bind them together with the binding idiom; on the static Astro
target the binding lowers to one-way (INK0045).

## Slots

The Hamburger Menu has no slots. Its content is the animated bar element, which
is decorative and hidden from assistive technology — the accessible name comes
from `ariaLabel`.

## Composition

`IHamburgerMenu` is a styled wrapper around a headless base,
`IHamburgerMenuBase`, which carries the button, the disclosure state and the ARIA
wiring and none of the styling or animation. Import the base from
`@inkline/<framework>/headless` when you want the mechanics under your own CSS —
see
[Your first component](/docs/getting-started/first-component#drop-the-styling-the-headless-layer).
