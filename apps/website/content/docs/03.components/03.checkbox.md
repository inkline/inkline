The Checkbox is a labelled boolean control. It pairs a native
`<input type="checkbox">` with its `<label>`, and exposes a two-way `checked`
state alongside the usual `disabled`, `readonly`, `required` and `indeterminate`
flags.

## Props

| Prop            | Type                              | Default     | Description                                                            |
| --------------- | --------------------------------- | ----------- | ---------------------------------------------------------------------- |
| `checked`       | `boolean`                         | —           | Two-way checked state. Pairs with the `update:checked` event.          |
| `label`         | `string`                          | —           | Label text; overridden by the default slot.                            |
| `color`         | `"light" \| "dark" \| "neutral"`  | `"neutral"` | Box color variant.                                                     |
| `size`          | `"sm" \| "md" \| "lg"`            | `"md"`      | Size variant, applied to both the wrapper and the box.                 |
| `id`            | `string`                          | —           | Id of the native control.                                              |
| `name`          | `string`                          | —           | Name of the native control, used for form submission.                  |
| `disabled`      | `boolean`                         | —           | Disables the control.                                                  |
| `required`      | `boolean`                         | —           | Marks the control as required.                                         |
| `readonly`      | `boolean`                         | —           | Shows the state but blocks changes; the control stays focusable.       |
| `indeterminate` | `boolean`                         | —           | Renders the third, mixed state. Applied as a DOM property.             |

`id`, `name`, `disabled`, `required`, `readonly` and `indeterminate` are declared
on `CheckboxControlBaseProps`; `label` on `CheckboxProps`. `color` and `size`
come from the `checkbox-field` Styleframe recipe, so their unions and defaults
are the recipe's.

`readonly` differs from `disabled`: a read-only checkbox is still focusable and
still submits with the form, it just refuses to flip. A native checkbox ignores
the HTML `readonly` attribute, so this is enforced behaviourally and announced
with `aria-readonly`.

## Events

| Event            | Payload   | Description                                        |
| ---------------- | --------- | -------------------------------------------------- |
| `update:checked` | `boolean` | Fired when the user toggles the box. |

`checked` and `update:checked` are the two halves of one `defineModel`. In
frameworks that support it, bind them together with the binding idiom; on the
static Astro target the binding lowers to one-way (INK0045).

## Slots

| Slot      | Description                                                    |
| --------- | -------------------------------------------------------------- |
| `default` | Label content. Falls back to the `label` prop when left empty. |

## Composition

`ICheckbox` is a styled wrapper around two headless parts: `ICheckboxBase`, the
`<label>` that wraps control and text, and `ICheckboxControlBase`, the native
input that owns the checked state. Import them from
`@inkline/<framework>/headless` when you want the mechanics under your own CSS —
see
[Your first component](/docs/getting-started/first-component#drop-the-styling-the-headless-layer).
