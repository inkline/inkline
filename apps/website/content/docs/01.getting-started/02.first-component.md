You have the package installed. This page takes you from an empty file to a
button you can click, then shows you the two things you will reach for next:
props and the headless layer.

If you have not installed yet, start at
[Installation](/docs/getting-started/installation).

## Render a button

Import the component and render it. `label` is the text.

::framework-switcher
#react

```tsx [src/App.tsx]
import { IButton } from "@inkline/react";

export default function App() {
  return <IButton label="Save changes" />;
}
```

#vue

```vue [src/App.vue]
<script setup lang="ts">
import { IButton } from "@inkline/vue";
</script>

<template>
  <IButton label="Save changes" />
</template>
```

#svelte

```svelte [src/App.svelte]
<script lang="ts">
  import { IButton } from "@inkline/svelte";
</script>

<IButton label="Save changes" />
```

#solid

```tsx [src/App.tsx]
import { IButton } from "@inkline/solid";

export default function App() {
  return <IButton label="Save changes" />;
}
```

#angular

`IButton` is a standalone component with the selector `ink-button`. Add it to
`imports`, then use the selector in your template.

```ts [src/app/app.component.ts]
import { Component } from "@angular/core";
import { IButton } from "@inkline/angular";

@Component({
  standalone: true,
  selector: "app-root",
  imports: [IButton],
  template: `<ink-button label="Save changes" />`,
})
export class AppComponent {}
```

#qwik

```tsx [src/routes/index.tsx]
import { component$ } from "@qwik.dev/core";
import { IButton } from "@inkline/qwik";

export default component$(() => <IButton label="Save changes" />);
```

#astro

```astro [src/pages/index.astro]
---
import { IButton } from "@inkline/astro";
---

<IButton label="Save changes" />
```

::

The component renders a native `<button>` — not a `<div>` wearing a button
costume — so keyboard focus, form submission and assistive technology work
without anything extra from you:

```html
<button class="button …" type="button" aria-busy="false">Save changes</button>
```

## Pass props

Three props control appearance: `color`, `variant` and `size`. They compose, and
they are the same names in all seven frameworks.

::framework-switcher
#react

```tsx
<IButton label="Delete" color="error" variant="outline" size="sm" />
```

#vue

```vue-html
<IButton label="Delete" color="error" variant="outline" size="sm" />
```

#svelte

```svelte
<IButton label="Delete" color="error" variant="outline" size="sm" />
```

#solid

```tsx
<IButton label="Delete" color="error" variant="outline" size="sm" />
```

#angular

```html
<ink-button label="Delete" color="error" variant="outline" size="sm" />
```

#qwik

```tsx
<IButton label="Delete" color="error" variant="outline" size="sm" />
```

#astro

```astro
<IButton label="Delete" color="error" variant="outline" size="sm" />
```

::

The full set for `IButton`:

| Prop       | Type                                                                                      | Default   | Description                  |
| ---------- | ----------------------------------------------------------------------------------------- | --------- | ---------------------------- |
| `label`    | `string`                                                                                  | —         | Button text content.         |
| `color`    | `primary \| secondary \| success \| info \| warning \| error \| light \| dark \| neutral` | `neutral` | Color variant.               |
| `variant`  | `solid \| outline \| soft \| subtle \| ghost \| link`                                     | `solid`   | Style variant.               |
| `size`     | `xs \| sm \| md \| lg \| xl`                                                              | `md`      | Size variant.                |
| `type`     | `button \| submit \| reset`                                                               | `button`  | Native button type.          |
| `disabled` | `boolean`                                                                                 | `false`   | Disables the button.         |
| `loading`  | `boolean`                                                                                 | `false`   | Shows a loading spinner.     |
| `block`    | `boolean`                                                                                 | `false`   | Renders a full-width button. |

Every prop you do not recognize as Inkline's is forwarded to the underlying
element, so `onClick`, `id`, `data-*` and `aria-*` behave the way they do on any
native button.

## Use the content slot instead of `label`

`label` is the shortcut for plain text. For anything richer — an icon, a nested
element — pass children instead. Children win over `label` when both are given.

::framework-switcher
#react

```tsx
<IButton color="primary">
  <SaveIcon /> Save changes
</IButton>
```

#vue

```vue-html
<IButton color="primary">
  <SaveIcon /> Save changes
</IButton>
```

#svelte

```svelte
<IButton color="primary">
  <SaveIcon /> Save changes
</IButton>
```

#solid

```tsx
<IButton color="primary">
  <SaveIcon /> Save changes
</IButton>
```

#angular

```html
<ink-button color="primary"> <app-save-icon /> Save changes </ink-button>
```

#qwik

```tsx
<IButton color="primary">
  <SaveIcon /> Save changes
</IButton>
```

#astro

```astro
<IButton color="primary">
  <SaveIcon /> Save changes
</IButton>
```

## Drop the styling: the headless layer

Every styled component has a headless counterpart on the `/headless` subpath. It
is the same structure, the same state and the same accessibility wiring, with no
classes attached — the escape hatch for when your design has nothing in common
with the default theme.

::framework-switcher
#react

```tsx
import { IButtonBase } from "@inkline/react/headless";

<IButtonBase className="my-own-button" label="Save changes" />;
```

#vue

```vue
<script setup lang="ts">
import { IButtonBase } from "@inkline/vue/headless";
</script>

<template>
  <IButtonBase class="my-own-button" label="Save changes" />
</template>
```

#svelte

```svelte
<script lang="ts">
  import { IButtonBase } from "@inkline/svelte/headless";
</script>

<IButtonBase class="my-own-button" label="Save changes" />
```

#solid

```tsx
import { IButtonBase } from "@inkline/solid/headless";

<IButtonBase class="my-own-button" label="Save changes" />;
```

#angular

```ts
import { IButtonBase } from "@inkline/angular/headless";
```

```html
<ink-button-base klass="my-own-button" label="Save changes" />
```

#qwik

```tsx
import { IButtonBase } from "@inkline/qwik/headless";

<IButtonBase class="my-own-button" label="Save changes" />;
```

#astro

```astro
---
import { IButtonBase } from "@inkline/astro/headless";
---

<IButtonBase class="my-own-button" label="Save changes" />
```

::

Reach for headless only when you are replacing the design wholesale. If you just
want different colors and spacing, keep the styled components and change the
tokens — that is [Theming](/docs/getting-started/theming), and it is one config
file.
