Inkline ships one package per framework. Install the one that matches your app —
you never install more than one, and there is nothing to configure afterwards.

Pick your framework in the tabs below. Every tab shows the package to install,
the peer dependency it expects, and the import that loads the component styles.

## Install the package

::framework-switcher
#react

```bash
npm install @inkline/react
```

Peer dependency: `react` 18 or newer.

#vue

```bash
npm install @inkline/vue
```

Peer dependency: `vue` 3 or newer.

#svelte

```bash
npm install @inkline/svelte
```

Peer dependency: `svelte` 5 or newer.

#solid

```bash
npm install @inkline/solid
```

Peer dependency: `solid-js` 1 or newer.

#angular

```bash
npm install @inkline/angular
```

Peer dependency: `@angular/core` 17 or newer.

#qwik

```bash
npm install @inkline/qwik
```

Peer dependency: `@qwik.dev/core` 2.0.0-beta.0 or newer.

#astro

```bash
npm install @inkline/astro
```

Peer dependency: `astro` 4 or newer.
::

Use `pnpm add`, `yarn add` or `bun add` if that is your package manager — the
package name does not change.

The package brings one runtime dependency with it, `@styleframe/runtime`, which
resolves the design tokens the components read. Everything else is a peer
dependency you already have.

## Load the styles

Inkline components carry classes, not inline styles. Import the stylesheet once,
at the entry point of your app, before anything renders.

::framework-switcher
#react

```ts [src/main.tsx]
import "@inkline/react/css";
```

#vue

```ts [src/main.ts]
import "@inkline/vue/css";
```

#svelte

```ts [src/main.ts]
import "@inkline/svelte/css";
```

#solid

```ts [src/index.tsx]
import "@inkline/solid/css";
```

#angular

The Angular package ships no bundled stylesheet. Build the CSS from a
`styleframe.config.ts` in your project and add it to the `styles` array in
`angular.json` — see [Theming](/docs/getting-started/theming), which walks
through exactly that.

#qwik

The Qwik package ships no bundled stylesheet. Build the CSS from a
`styleframe.config.ts` in your project and import it from your root component —
see [Theming](/docs/getting-started/theming), which walks through exactly that.

#astro

```ts [src/layouts/Layout.astro]
import "@inkline/astro/css";
```

::

That stylesheet is the default theme. Once you want your own brand colors,
spacing or radii, you stop importing it and generate your own — one config file,
covered in [Theming](/docs/getting-started/theming).

::warning
Two targets are missing the bundled stylesheet by design, and it is called out in
the tabs above rather than hidden: **Angular** and **Qwik** have no `/css` entry
point. [Framework support](/docs/getting-started/framework-support) lists every
such difference in one table.
::

## Verify the install

Render one component. If it appears and it is styled, you are done.

::framework-switcher
#react

```tsx [src/App.tsx]
import { IButton } from "@inkline/react";

export default function App() {
  return <IButton label="It works" color="primary" />;
}
```

#vue

```vue [src/App.vue]
<script setup lang="ts">
import { IButton } from "@inkline/vue";
</script>

<template>
  <IButton label="It works" color="primary" />
</template>
```

#svelte

```svelte [src/App.svelte]
<script lang="ts">
  import { IButton } from "@inkline/svelte";
</script>

<IButton label="It works" color="primary" />
```

#solid

```tsx [src/App.tsx]
import { IButton } from "@inkline/solid";

export default function App() {
  return <IButton label="It works" color="primary" />;
}
```

#angular

```ts [src/app/app.component.ts]
import { Component } from "@angular/core";
import { IButton } from "@inkline/angular";

@Component({
  standalone: true,
  selector: "app-root",
  imports: [IButton],
  template: `<ink-button label="It works" color="primary" />`,
})
export class AppComponent {}
```

#qwik

```tsx [src/routes/index.tsx]
import { component$ } from "@qwik.dev/core";
import { IButton } from "@inkline/qwik";

export default component$(() => <IButton label="It works" color="primary" />);
```

#astro

```astro [src/pages/index.astro]
---
import { IButton } from "@inkline/astro";
---

<IButton label="It works" color="primary" />
```

::

A styled button means the package resolved and the stylesheet loaded. An
_unstyled_ button — plain browser default, no color — means the component
resolved but the stylesheet did not: check that the `/css` import runs before
your app renders.
